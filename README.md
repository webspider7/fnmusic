## 🌟 为什么选择极光音乐？

很多 NAS 音乐播放方案依赖庞大的 Docker 容器或臃肿的网页套件，启动慢、占用内存大，并且难以深度融合 NAS 本地目录与现代流媒体听歌体验。

**极光音乐 (fnmusic)** 专为飞牛 NAS 生态定制设计：
- 采用**飞牛原生 FPK 应用架构**（非 Docker），单个静态编译二进制直接在 Debian 底层高效运行；
- 常驻内存仅约 **15MB ~ 25MB**，极低 CPU 负载，零机械硬盘无效唤醒；
- 兼备**黑胶唱机沉浸式视听**、**NAS 本地音乐无损串流**、**多音源自动容灾降级**与**全局后台持久下载**。

## ✨ 核心亮点

### 1. 💽 黑胶唱机沉浸式视听空间
- **高颜值交互**：黑胶唱片旋转动效、高保真流光氛围背景、全屏响应式适配（支持手机/平板/电脑大屏）。
- **专业级歌词体验**：支持双语翻译同步对照、字体大小调节、点击歌词任意行快速跳转播放、一键快速复制歌词。
- **多种播放循环模式**：顺序播放、随机播放、单曲循环一键切换。

### 2. 📁 NAS 本地音乐库原盘扫描与串流
- **多格式全兼容**：深度扫描飞牛各存储卷（`/vol1`、`/vol2` 等）中的音频文件（FLAC、APE、WAV、DSD、MP3、AAC、OGG 等）。
- **原盘无损高码率**：支持 HTTP 206 分片流式高保真串流，自动解析歌曲内嵌封面与 ID3 标签，歌词自动关联。
- **存储目录随时随地切换**：内置目录树浏览器，可自由指定歌曲存储与扫描路径。

### 3. 🧩 纯净容器架构 & 自定义第三方音源规则
- **完全开源合规**：本播放器为纯本地播放器容器，**不内置、不捆绑任何版权在线音源解析爬虫**。
- **音源脚本一键导入**：全面兼容标准的第三方音源脚本规则。支持本地 `.js` 脚本上传，或输入网络订阅链接一键导入。
- **秒级自动容灾降级**：可导入多个备用音源，主音源失效或限流时秒级自动无缝降级切换，听歌永不中断。

### 4. 📥 全局独立后台下载管理（切页不中断）
- **持久化下载系统**：下载状态挂载于全局服务，在「发现音乐」、「本地音乐」、「音源管理」之间自由切换，任务绝不中断。
- **静默后台入队**：点击「一键下载全部」或单曲下载，后台静默加入队列，微提示 Toast 友好反馈，不遮挡当前界面。
- **全能控制**：支持全局「全部暂停」、「全部继续」、「停止全部」，单曲任务卡片均提供暂停、继续、重试与取消，支持「已暂停」标签独立分类。

### 5. 🚀 GitHub Release 自动更新检测
- **内置在线版本检查**：直接对接官方 GitHub Release API，自动对比语义化版本号。
- **一键下载升级**：应用内点击即可获取最新 FPK 安装包，更新日志一目了然，保留全部配置与下载歌曲无缝升级。

## 📥 飞牛 NAS 安装使用指南

### 方式一：飞牛应用中心手动安装（推荐）

1. **下载最新安装包**：
   前往 GitHub Releases 页面下载最新版：  
   👉 [**下载 fn-lx-player.fpk**](https://github.com/webspider7/fnmusic/releases/latest)
2. **在飞牛应用中心安装**：
   - 登录飞牛 NAS 管理后台，点击进入桌面的**【应用中心】**；
   - 点击界面**左下角**的**【手动安装】**按钮；
   - 选择并上传下载好的 `fn-lx-player.fpk` 文件；
   - 确认安装，等待几秒即可在飞牛桌面看到全新的**「极光音乐」**图标！
3. **升级更新**：
   - 后续有新版本时，直接在应用内「更新」弹窗下载新版 FPK，重复上述步骤覆盖安装，所有音源与数据完全保留。

## 🎧 音源规则导入指引

由于极光音乐为纯净本地播放器容器，初次使用时如需试听网络曲库，需导入第三方音源脚本：

1. 打开应用，点击顶部导航栏的**【音源管理】**；
2. **导入方式 A（网络订阅）**：在「在线导入」输入框中填入公开的音源订阅链接（例如 `http://.../latest.js`），点击导入；
3. **导入方式 B（本地文件）**：点击「本地上传脚本」，选择保存到本地的 `.js` 音源脚本文件上传；
4. 导入成功后，在列表中将该音源设为激活状态，返回「发现音乐」即可畅享网络搜索、榜单与精选歌单推荐。
